# 01 · 环境搭建与项目跑通

> **本篇你会学到**：装齐工具 → 导入项目 → 点 Run → 在手机上看到启动页。
> **预计耗时**：1~2 小时（下载占大头）

---

## 1.1 先搞明白：写 Android 需要哪几样东西

用做饭打比方：

| 东西 | 类比 | 作用 |
|---|---|---|
| **JDK**（Java 开发工具包） | 灶台 | 编译 Java 代码的引擎 |
| **Android Studio** | 厨房 | 写代码的软件（IDE） |
| **Android SDK** | 食材仓库 | 各种 Android 版本的库和工具 |
| **Gradle** | 菜谱执行器 | 按配置把源码"做"成 APK |
| **模拟器 / 真机** | 餐桌 | 跑起来看效果的地方 |

好消息：**装 Android Studio 时，JDK 和 SDK 都会一起装好**，你只需要装一个软件。

---

## 1.2 安装 Android Studio

1. 打开 <https://developer.android.com/studio>
2. 下载对应系统的安装包（Windows 选 `.exe`）
3. 一路 Next，安装位置默认即可
4. 首次启动会弹出 **Setup Wizard**，选 **Standard**（标准安装），它会自动下载：
   - 最新版 SDK
   - 模拟器（Emulator）
   - 构建工具（Build-Tools）

> ⚠️ **本项目要求较新的 Android Studio**。因为项目用的是 **AGP 9.2.1 + Gradle 9.4.1 + compileSdk 36**，太老的版本打开会提示"插件版本不支持"。建议用 2025 年底之后发布的版本。

安装完打开，看到欢迎界面就说明成功了。

---

## 1.3 导入项目

1. 欢迎界面点 **Open**（不要点 New Project）
2. 选中文件夹：`AndroidFinalProject/BookMall`
   > 注意是 **BookMall 这一层**，不是它的上一层
3. 点 OK

这时 Android Studio 会开始 **Gradle Sync**（右下角转圈，底部有进度条）。

### Gradle Sync 在干什么？

它在读这几个文件，然后去下载项目需要的"零件"：

```
BookMall/
├── settings.gradle.kts          ← 告诉 Gradle：这个项目包含哪些模块
├── build.gradle.kts             ← 顶层配置（一般不用改）
├── gradle.properties            ← 给 Gradle 的全局参数
├── local.properties             ← 你的 SDK 装在哪（自动生成，不进 Git）
├── gradle/
│   ├── libs.versions.toml       ← 依赖版本清单（重要！）
│   └── wrapper/
│       └── gradle-wrapper.properties  ← 用哪个版本的 Gradle
└── app/
    └── build.gradle.kts         ← app 模块的配置（依赖、SDK 版本）
```

**第一次 Sync 可能要 5~15 分钟**，因为要下载 Gradle 本体和所有依赖库。泡杯茶等着。

## 1.4 认识这几个配置文件（不用背，混个脸熟）

### `settings.gradle.kts` —— 项目有哪些模块

```kotlin
rootProject.name = "BookMall"
include(":app")
```

- `rootProject.name` = 项目名，会显示在 Android Studio 标题栏
- `include(":app")` = 这个项目包含一个叫 `app` 的模块

> **为什么只有 app 一个模块？** 因为这是单模块项目。大公司项目会有 `:app`、`:login`、`:common` 等多个模块，互相依赖。我们的项目规模小，一个模块够了。

### `gradle/libs.versions.toml` —— 依赖版本清单

```toml
[versions]
agp = "9.2.1"
appcompat = "1.8.0"
material = "1.14.0"
recyclerview = "1.2.1"

[libraries]
appcompat = { group = "androidx.appcompat", name = "appcompat", version.ref = "appcompat" }
material = { group = "com.google.android.material", name = "material", version.ref = "material" }
recyclerview = { group = "androidx.recyclerview", name = "recyclerview", version.ref = "recyclerview" }
```

这个文件叫 **Version Catalog**（版本目录）。好处是：版本号只写一遍，多个模块共用，升级时改一处就行。

**本项目用了哪几个库？**

| 库 | 作用 | 你在哪见过它 |
|---|---|---|
| `appcompat` | 让老系统也能用新特性，提供 `AppCompatActivity` | 每个 Activity 都继承它 |
| `material` | Material Design 组件（按钮、卡片、底部导航） | `MaterialButton`、`MaterialCardView`、`BottomNavigationView` |
| `recyclerview` | 列表控件 | 8 个列表全靠它 |

> **命名解读**：`libs.versions.toml` 里的 `appcompat` 是 **app + compat**（application compatibility，应用兼容），所以叫这个名字。`material` 就是"材料/材质设计"，Google 2014 年推出的一套视觉规范。

### `app/build.gradle.kts` —— 这个 App 怎么构建

```kotlin
android {
    namespace = "com.yzc.bookmall"      // 代码的包名前缀
    compileSdk { version = release(36) { minorApiLevel = 1 } }  // 用 API 36 编译

    defaultConfig {
        applicationId = "com.yzc.bookmall"  // 装到手机上后的唯一标识
        minSdk = 24        // 最低支持 Android 7.0
        targetSdk = 36     // 目标是 Android 16
        versionCode = 1    // 内部版本号（整数，每次发版 +1）
        versionName = "1.0" // 给用户看的版本号
    }
}
```

**三个 SDK 版本的区别**（面试常问）：

| 名字 | 含义 | 本项目的值 |
|---|---|---|
| `compileSdk` | 用哪个版本的 SDK **编译**代码 | 36 |
| `minSdk` | 最低能装到哪个版本，低于这个装不上 | 24（Android 7.0） |
| `targetSdk` | 告诉系统"我适配到这个版本了"，系统会按这个版本的行为对待你 | 36 |

> **为什么 minSdk 是 24？** 24 = Android 7.0（2016 年）。设太高会丢掉老设备用户，设太低很多新 API 用不了。24 是现在比较常见的折中值。

> **命名解读**：`applicationId` 是**应用 ID**，手机和 Google Play 靠它区分 App。它和 `namespace` 通常一样，但可以不同——`namespace` 管代码的包名，`applicationId` 管安装后的身份。

### `local.properties` —— 你的 SDK 在哪

```properties
sdk.dir=D\:\\APP\\AndroidSdk
```

这行是 Android Studio **自动生成**的，每台电脑路径不同，所以它被写进了 `.gitignore`，**不会提交到 Git**。

> 如果你 clone 了别人的项目发现报错"SDK location not found"，就是这个文件缺了。用 Android Studio 打开一次会自动补上。

## 1.5 准备一台"手机"

两种选择：

### 方案 A：模拟器（推荐新手）

1. 右上角工具栏找 **Device Manager**（图标像个小手机）
2. 点 **Create Virtual Device**
3. 选 **Pixel 6** 之类的机型 → Next
4. 系统镜像选 **API 34** 或更高（带 Google APIs 的）→ Download → Next → Finish
5. 启动它

> 模拟器很吃内存。如果电脑卡，装 API 30 左右的镜像会轻一些。

### 方案 B：真机

1. 手机打开 **开发者选项**（设置 → 关于手机 → 连点"版本号"7 次）
2. 打开 **USB 调试**
3. 数据线连电脑，手机上点"允许调试"

## 1.7 跑不通？对照这张表

| 现象 | 原因 | 解决 |
|---|---|---|
| `SDK location not found` | 缺 `local.properties` | File → Sync Project with Gradle Files |
| `Unsupported class file major version` | JDK 版本不对 | File → Settings → Build → Gradle → Gradle JDK 选 17 或 21 |
| `Plugin [id: 'com.android.application', version: '9.2.1'] was not found` | 网络问题，依赖没下下来 | 挂代理，或 File → Invalidate Caches |
| 编译成功但装不上 | 设备没连上 | 看顶部设备下拉框是否有你的手机/模拟器 |
| 打开就闪退 | 数据库初始化异常 | 看 Logcat（第 14 篇教你怎么看） |
| 界面一片白 | 主题或布局问题 | 同样看 Logcat 的红色报错 |

### 关于 Gradle 的两个实用操作

- **Sync Now**：改了 `build.gradle.kts` 或 `libs.versions.toml` 后，右上角会出现一条黄条，点它重新同步
- **Clean Project**：Build → Clean Project，删掉构建产物重来。玄学问题时先点这个
