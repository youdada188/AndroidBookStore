# 书墨商城 · 零基础学习教程

> 写给**完全没接触过 Android** 的你。
> 目标：读完之后，你能看懂这个项目的每一行代码，能自己改功能，能在答辩时讲清楚每个设计决策。

---

## 一、这套教程怎么用

这不是一本"Android 大全"，而是**围绕这一个项目**写的解剖课。每一篇都会：

1. 先用生活化的比喻讲清楚概念；
2. 立刻贴上**项目里真实的代码**；
3. 逐行解释，包括**为什么这个变量叫这个名字**；
4. 最后给几道自测题，答不上来就回去重读。

代码里的变量名不是随便起的。`priceFen` 的 `Fen` 是"分"，`dbHelper` 的 `Helper` 是"帮手"，`adapter` 的 `Adapter` 是"适配器"——这些词在 Android 世界里是有约定含义的。**看懂了命名，就看懂了一半架构。**

## 五、项目一句话介绍

**书墨商城**是一个**完全离线**的图书购物 App：

- 打开先看到 5 家书店
- 点进书店看到店里的书
- 点进书看到详情，可以收藏、加购物车
- 购物车里勾选、改数量、去结算
- 填收货地址、用优惠券、提交订单
- 在"我的"里看订单、确认收货、写评价

**全程不需要联网**，数据都存在手机本地的 SQLite 数据库里。

## 六、这个项目用了哪些技术（对应老师的要求）

## 七、先看一眼代码规模

```
app/src/main/java/com/yzc/bookmall/
├── model/      6 个类   实体（Book、Store、Order…）
├── data/       3 个类   数据库与数据读写
├── ui/         13 个页面 + 8 个适配器 + 4 个 Fragment
└── util/       2 个工具类

app/src/main/res/
├── layout/     28 个布局文件
├── drawable/   30 个图标与背景
└── values/     颜色、字符串、主题
```

一共 43 个 Java 文件、约 4200 行代码。**看起来多，其实套路就那几套**，学完 12 篇你会发现大量代码是重复的模板。

## 八、阅读建议

1. **手边开着 Android Studio**，看到代码就跳过去点开对应文件，别只看不摸。
2. **遇到不懂的类名，先猜再查**。`StoreAdapter` —— Store 是书店，Adapter 是适配器，那它就是"把书店数据适配成列表项的东西"。
3. **每篇末尾的自测题，用嘴讲一遍**。能讲清楚，答辩就没问题。
4. **卡住超过 20 分钟就跳过**，先往后读，很多概念是读到第三遍才通的。
