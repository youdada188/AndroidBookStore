## 1. 选题定位

### 1.1 一句话定位

一个**完全离线**的图书商城 App：用户先逛「书店」，进店挑「书」，加入购物车，填写地址下单，在个人中心管理订单、评价和收货地址。

### 1.2 原型映射（订餐 → 书城）

教材原型是三层结构「店铺列表 → 店铺详情（菜品列表）→ 菜品详情」，本项目必须保持同样的三层深度，不能压平成两层：

| 教材「网上订餐」 | 本项目「书墨商城」 | 说明 |
|---|---|---|
| 店铺列表 / 首页 | 书店列表 / 首页 | 5 家主题书店（文学馆、社科馆、推理馆、绘本馆、生活馆） |
| 店铺详情 + 菜品列表 | 书店详情 + 图书列表 | 店铺评分、公告、营业时间、起送价 + 店内图书 |
| 菜品详情 | 图书详情 | 封面、书名、作者、出版社、价格、简介、库存 |
| 菜品分类 | 图书分类 | 文学 / 社会纪实 / 小说 / 历史文化 / 绘本漫画 |
| 购物车 | 购物车 | 按店铺分组展示 |
| 订单提交 | 订单提交 | 收货信息 + 事务扣库存 |

### 1.3 差异化合规自查

老师要求：不得直接使用「网上订餐」的名称、素材、图标和配色，需自定义 App 名称、图标、配色、商品数据和界面布局。

| 检查项 | 本项目做法 | 状态 |
|---|---|---|
| App 名称 | 「书墨商城」，与订餐无关 | 已合规 |
| 商品数据 | 20 本真实中文图书（真实书名/作者/出版社/简介）+ 真实书封 | 已合规 |
| 配色 | 主色深蓝 `#1E3A5F` + 强调色暖橙 `#D97706`，非外卖类红黄配色 | 已合规 |
| 界面布局 | 全部自行设计，未套用任何外卖模板 | 已合规 |
| 图标 | **当前仍是 Android 模板默认机器人图标** | ⚠ 待替换 |

## 2. 用户与业务流程

### 2.1 角色

单一角色：**买家**（不做商家后台，与原型一致）。

### 2.2 主流程

```
启动页（3s 倒计时）
   ├─ 已登录 ──→ 首页（书店列表）
   └─ 未登录 ──→ 登录页 ──→ 首页
                      └─→ 注册页

首页（书店列表）
   └─→ 书店详情（店铺信息 + 店内图书列表）
          └─→ 图书详情（封面/价格/简介/评价）
                 ├─→ 收藏
                 └─→ 加入购物车

购物车（勾选 / 增减 / 删除 / 合计）
   └─→ 确认订单（收货地址 + 优惠券 + 金额明细）
          └─→ 提交订单（事务：校验库存 → 写订单 → 扣库存 → 清购物车）
                 └─→ 订单详情 ──→ 确认收货

个人中心
   ├─→ 我的订单
   ├─→ 我的收藏
   ├─→ 收货地址管理
   ├─→ 我的评价
   └─→ 退出登录 / 清空当前账号数据
```

### 2.3 登录保护规则

- 游客可浏览：首页、书店详情、图书详情、搜索。
- 需登录：收藏、加入购物车、结算、订单、评价、地址管理、个人中心。
- 未登录触发受限操作时，跳转登录页，登录成功后**回到原入口**（不是回首页）。

## 3. 功能模块清单

### 3.1 必做模块（老师要求，全部实现）

#### M1 店铺页面（书店列表 / 首页）

- 顶部：App 名称 + 搜索入口。
- 书店卡片列表（RecyclerView）：店铺 logo、名称、一句话简介、评分、起送价、配送费、在售图书数。
- 点击卡片进入书店详情。
- 每次进入或从子页面返回时自动重新读取数据库刷新列表。
- 状态：加载中 / 空 / 错误重试。

#### M2 店铺详情页

- 店铺头部：logo、名称、评分、公告、营业时间、地址、配送费、起送价。
- 店内分类筛选（横向 chip，切换后过滤图书）。
- 店内图书列表（RecyclerView）：封面、书名、作者、价格、销量、库存。
- 点击图书进入图书详情。
- 状态：加载中 / 空（该分类无书）/ 错误重试。

#### M3 图书详情页

- 大图封面、书名、作者、出版社、价格、库存、简介。
- 数量选择器（步进器，上限为库存）。
- 「加入购物车」按钮，库存不足时禁用并提示。
- 「收藏 / 取消收藏」按钮（需登录）。
- 评价区：平均分 + 条数 + 最新 3 条评价。
- 状态：加载中 / 错误重试。

#### M4 订单页面（确认与提交）

- 确认订单页：商品清单、数量、小计、优惠券、配送费、实付合计。
- 收货地址：从地址簿选择，或跳转新增地址。
- 提交前二次确认对话框。
- 提交逻辑（单事务）：重查库存 → 任一不足则整单失败并提示具体书名 → 写订单 → 写明细快照 → 扣库存 → 删除已购购物车行。
- 提交成功进入订单详情。
- 订单列表（RecyclerView）：订单号、下单时间、商品摘要、件数、状态、实付金额，按时间倒序。
- 订单详情：收货信息、商品明细（价格快照）、金额明细、状态、确认收货按钮。

### 5.2 新增表结构

```sql
CREATE TABLE stores (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  name TEXT NOT NULL UNIQUE,
  slogan TEXT NOT NULL,
  description TEXT NOT NULL,
  logo_res_id INTEGER NOT NULL,
  rating REAL NOT NULL DEFAULT 5.0,
  address TEXT NOT NULL,
  business_hours TEXT NOT NULL,
  notice TEXT NOT NULL,
  delivery_fee_fen INTEGER NOT NULL DEFAULT 0,
  min_order_fen INTEGER NOT NULL DEFAULT 0,
  created_at INTEGER NOT NULL
);

CREATE TABLE reviews (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  user_id INTEGER NOT NULL,
  book_id INTEGER NOT NULL,
  order_id INTEGER NOT NULL,
  rating INTEGER NOT NULL,
  content TEXT NOT NULL,
  created_at INTEGER NOT NULL,
  UNIQUE(user_id, book_id),
  FOREIGN KEY(user_id) REFERENCES users(id) ON DELETE CASCADE,
  FOREIGN KEY(book_id) REFERENCES books(id) ON DELETE CASCADE
);

CREATE TABLE addresses (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  user_id INTEGER NOT NULL,
  name TEXT NOT NULL,
  phone TEXT NOT NULL,
  region TEXT NOT NULL,
  detail TEXT NOT NULL,
  is_default INTEGER NOT NULL DEFAULT 0,
  created_at INTEGER NOT NULL,
  FOREIGN KEY(user_id) REFERENCES users(id) ON DELETE CASCADE
);

CREATE TABLE coupons (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  title TEXT NOT NULL,
  threshold_fen INTEGER NOT NULL,
  discount_fen INTEGER NOT NULL,
  valid_until INTEGER NOT NULL
);

CREATE TABLE user_coupons (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  user_id INTEGER NOT NULL,
  coupon_id INTEGER NOT NULL,
  used INTEGER NOT NULL DEFAULT 0,
  UNIQUE(user_id, coupon_id),
  FOREIGN KEY(user_id) REFERENCES users(id) ON DELETE CASCADE,
  FOREIGN KEY(coupon_id) REFERENCES coupons(id) ON DELETE CASCADE
);
```

### 5.3 金额与一致性约定（沿用现有做法）

- 所有金额用 `int` 以「分」存储与计算，仅在展示层格式化为 `¥12.99`。
- 订单明细保存 `title_snapshot` / `price_snapshot_fen`，后续改价不影响历史订单。
- 下单、清空账号数据使用 SQLite 事务，失败整体回滚。
- 数据库版本升级采用 `onUpgrade` 增量迁移，**不再删表重建**（现有实现会丢数据且导致 `book_id` 错位）。

## 7. 状态与异常规范

### 7.1 四态模型

每个数据页面统一实现四种状态，不允许出现白屏：

| 状态 | 表现 | 触发 |
|---|---|---|
| LOADING | 居中 ProgressBar + "加载中…" | 首次进入 / 下拉刷新 |
| CONTENT | 正常内容 | 有数据 |
| EMPTY | 图标 + 文案 + 可选按钮 | 查询结果为空 |
| ERROR | 文案 + "重试"按钮 | 数据库/解析异常 |

### 7.2 异常兜底清单

| 场景 | 处理 |
|---|---|
| 图书 / 订单不存在 | 提示后关闭页面，不崩溃 |
| 库存不足下单 | 整单回滚，提示具体书名，返回购物车 |
| 数量输入非法（空、0、负数、非数字） | 步进器限制范围，禁用非法输入 |
| 数据库初始化失败 | 显示错误页 + 重试 |
| JSON 解析失败 | 回退到内置最小数据集，记录日志，不白屏 |
| 订单号重复 | 生成器加随机后缀，避免唯一约束崩溃 |
| 未登录访问受限页 | 跳登录页，登录后回到原入口 |

## 8. 验收标准与演示脚本

### 8.1 验收清单

1. 冷启动出现 Logo 与 3 秒倒计时，倒计时结束自动跳转，点「跳过」立即跳转。
2. 未登录进入登录页；注册新账号后可用新账号登录；错误密码有明确提示。
3. 首页展示 5 家书店，卡片信息完整，列表可滚动。
4. 进入书店详情能看到店铺公告、评分、起送价与店内图书，分类筛选生效。
5. 图书详情展示封面、价格、简介，数量上限受库存限制，可加入购物车与收藏。
6. 购物车可勾选、增减、删除，合计金额正确（分为单位）。
7. 结算页可选择地址、使用优惠券，实付金额 = 商品合计 + 配送费 − 优惠。
8. 提交订单后库存减少、购物车对应行被清除、订单列表出现新订单。
9. 订单详情可确认收货，状态由「待发货」变为「已完成」。
10. 重启 App 后登录态保留，收藏 / 购物车 / 订单 / 地址 / 评价数据仍在。
11. 断网状态下全流程可完成。
12. `./gradlew assembleDebug` 构建成功。

### 8.2 答辩演示顺序（约 6 分钟）

启动页 → 登录 → 首页书店列表 → 书店详情 → 图书详情 → 加购 → 购物车 → 结算（选地址 + 用券）→ 提交订单 → 订单详情 → 确认收货 → 个人中心 → 评价 → 退出登录。

## 9. 难度对比说明（答辩用）

| 维度 | 教材「网上订餐」 | 本项目 | 结论 |
|---|---|---|---|
| 页面层级 | 店铺 → 菜品 → 下单 | 书店 → 图书 → 下单 | 持平 |
| 页面数量 | 约 8 个 | 17 个（含 4 Fragment） | 更高 |
| 数据表 | 约 5 张 | 12 张 | 更高 |
| 列表实现 | ListView | RecyclerView + ViewHolder + 多布局 | 更高 |
| 数据来源 | 硬编码 / 简单接口 | 本地 JSON 解析入库 + SQLite | 持平偏上 |
| 事务一致性 | 一般无 | 下单全事务 + 库存校验 + 回滚 | 更高 |
| 状态管理 | 无 | 四态模型（加载/空/错误/内容） | 更高 |
| 扩展功能 | 无 | 评价、地址簿、优惠券、收藏 | 更高 |
